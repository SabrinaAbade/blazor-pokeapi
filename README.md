# BlazorPokeApi

Aplicação web desenvolvida em **Blazor WebAssembly** para consultar informações de Pokémon por meio da PokéAPI.

## Funcionalidades

- Pesquisa de Pokémon pelo nome.
- Consulta de informações diretamente da PokéAPI.
- Exibição da imagem do Pokémon.
- Exibição do ID, nome, altura e peso.
- Mensagens para pesquisa vazia e falhas na consulta.

## Tecnologias utilizadas

- C#
- .NET
- Blazor WebAssembly
- Razor
- PokéAPI

## API utilizada

Endpoint:

https://pokeapi.co/api/v2/pokemon/{nome}

Exemplo:

https://pokeapi.co/api/v2/pokemon/ditto

## Como executar

1. Instale o SDK do .NET.
2. Clone este repositório.
3. Entre na pasta do projeto:

   `cd BlazorPokeApi`

4. Execute:

   `dotnet run`

5. Abra no navegador o endereço informado no terminal.

## Objetivo

Atividade acadêmica da disciplina de Desenvolvimento Web, com o objetivo de consumir uma API e apresentar seus dados em uma aplicação Blazor WebAssembly.
